# W3–W6 Roadmap — Specs + Plans

Date: 2026-08-26
Mode: sequential waves, gated per wave (typecheck/vitest/build + push).

## W3 — Cash Flow Statement (indirect)
- `account.cf_category text not null default 'OPERATING'` enum OPERATING|INVESTING|FINANCING; backfill: INCOME/EXPENSE+is_cash→OPERATING, ASSET non-cash→INVESTING, LIABILITY/EQUITY→FINANCING. Editable in AccountForm.
- `getCashFlow({organizationId, companyId, from, to})`: signed deltas from getBalances opening(≤from) vs ending(≤to); NI = income−expenses; CFO = NI −ΔopAssets +ΔopLiab; CFI = −ΣΔ inv assets; CFF = ΣΔ fin liab/equity; reconcile vs ΣΔ is_cash.
- Page `/reports/cash-flow?company=`, three sections + reconciliation badge + drill links via ReportTable linkKeys; export `cash-flow` CSV/XLSX; Reports submenu entry.
- Fixture expectation: cash 102000 = CFF 100000 (capital) + CFO 2000 (NI 12000 − ΔAR 10000) + CFI 0.

## W4 — Attachments
- Storage bucket `attachments` (private) + RLS on storage.objects scoped by path `org/{orgId}/company/{companyId}/...`.
- Table `attachment(id, organization_id, company_id, journal_entry_id, file_name, mime_type, size_bytes, storage_path unique, uploaded_by_id, created_at)` + RLS select/insert/delete via membership join on company.
- Actions upload/list/delete (signed URL download). UI: AttachmentsCard on journal detail; /journal filters `doc=missing|with`.
- Dashboard "missing attachments" deferred to W6 tax package reuse.

## W5 — Reconciliation workspace
- Tables: `reconciliation(id, organization_id, company_id, account_id, start_date, end_date, statement_balance numeric, status OPEN|COMPLETE, created_by_id, created_at)` and `reconciliation_item(id, reconciliation_id, item_date, description, amount numeric, matched_line_id uuid null, created_at)`.
- Workspace `/reconciliation?company=`: create recon (pick account+range+statement balance), import statement CSV/XLSX (Date, Description, Amount | Debit/Credit), match items ↔ posted journal lines of that account in range (auto-match by amount+date ±3d then manual), header shows Ledger − Matched Schedule = Difference; Complete when diff 0 & all matched.

## W6 — Workpapers + Tax Center
- Workpapers `/workpapers?company=`: config-driven schedules (code-prefix patterns): Prepaid `14*`, Accrued `21*`, Fixed Assets `15*`, Accum Dep `16*`, Loans Payable `25*`, Receivables `11*`, Payables `20*`, VAT `22*`, Withholding `23*`. Each tab: accounts+balances as-of date + drill links + notes saved in `workpaper_note(company_id, schedule_key, period_end, notes)` upsert.
- Tax Center `/tax-center?company=`: profile card (classification/TIN/RDO/branch/address), filing calendar generated for year by classification rules (VAT: 2551M 20th/25th, 2551Q q+25th; PERCENTAGE: 2551B q; both: 1601C/C m15th, 1701Q/1702Q q+30th?, annual ITR Apr 15), statuses in `filing_status(company_id, form, due_date, status NOT_STARTED|FILED, filed_at, attachment_id?)`; proof-of-filing uses W4 attachments (entity FILING). Export summary CSV + print.
