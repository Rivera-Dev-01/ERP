# Projects (Clients) Implementation Plan — `?project=` flat, JE per Organization

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement slice-by-slice. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Give one `ACCOUNTANT` in one `Organization` (`V0 Accounting Demo 22222222-...`) multiple fully self-dependent ledgers — **Projects** — where each Project owns its own `account`/`fiscal_period`/`journal_entry+line`/`import_batch`/`audit_event` and reports (`120000/12000/112000` per Project), while `JE-YYYY-XXXX` (`journal_entry_sequence` per `organization_id`) stays organization-wide. Account code uniqueness, period overlap, and reports are per `project_id`; routing stays flat `?project=<uuid>` (default first ACTIVE, `Example Client`).

**Architecture:** Three slices in order: P1 schema+backfill (`project` + 5 `project_id` FKs, `unique (project_id,code)`, `exclude gist (project_id, daterange)`), P2 domain+server threading `projectId` through all `server/reports` + actions, P3 UI switcher + per-Project reports/export + 2-project isolation tests. No `[projectId]` folder move.

**Tech Stack:** Next.js 16.3.1 App Router TS strict + Tailwind + shadcn/ui `Select`/`Dialog` + TanStack Table + `@supabase/ssr` hosted `tdmcnbnyusxdegzopxhd` (`src/proxy.ts` `proxy`) + `server-only` + `decimal.js` + `Intl en-PH` + Zod + `papaparse`/`exceljs` already installed. No new framework.

**Spec:** `docs/superpowers/specs/2026-08-27-projects-design.md` (extends `2026-08-19-erp-v0-design.md` §5 + Phase 4 spec).

- [ ] **Step 1: Write `00015_projects.sql`**

```sql
create table public.project (
  id uuid primary key default gen_random_uuid(),
  organization_id uuid not null references public.organization(id) on delete cascade,
  name text not null check (char_length(name) between 1 and 120),
  client_name text check (char_length(client_name) between 0 and 120),
  status text not null default 'ACTIVE' check (status in ('ACTIVE','ARCHIVED')),
  created_at timestamptz not null default now(),
  unique (organization_id, name)
);
create index project_org_idx on public.project (organization_id);

-- add nullable first
alter table public.account add column project_id uuid references public.project(id) on delete cascade;
alter table public.fiscal_period add column project_id uuid references public.project(id) on delete cascade;
alter table public.journal_entry add column project_id uuid references public.project(id) on delete cascade;
alter table public.import_batch add column project_id uuid references public.project(id) on delete cascade;
alter table public.audit_event add column project_id uuid references public.project(id) on delete cascade;

-- default per org (example client)
insert into public.project (organization_id, name, client_name)
select id, 'Example Client', 'Example Client' from public.organization
on conflict (organization_id, name) do nothing;

-- backfill existing rows to their org's first project
update public.account set project_id = (select id from public.project where organization_id = account.organization_id limit 1) where project_id is null;
update public.fiscal_period set project_id = (select id from public.project where organization_id = fiscal_period.organization_id limit 1) where project_id is null;
update public.journal_entry set project_id = (select id from public.project where organization_id = journal_entry.organization_id limit 1) where project_id is null;
update public.import_batch set project_id = (select id from public.project where organization_id = import_batch.organization_id limit 1) where project_id is null;
-- audit_event backfill best-effort (may be empty)
update public.audit_event set project_id = (select id from public.project where organization_id = audit_event.organization_id limit 1) where project_id is null;

-- now not null for accounting tables
alter table public.account alter column project_id set not null;
alter table public.fiscal_period alter column project_id set not null;
alter table public.journal_entry alter column project_id set not null;
alter table public.import_batch alter column project_id set not null;

-- new uniques per project
alter table public.account drop constraint if exists account_organization_id_code_key;
alter table public.account add constraint account_project_code_key unique (project_id, code);
alter table public.fiscal_period drop constraint if exists fiscal_period_organization_id_name_key;
alter table public.fiscal_period add constraint fiscal_period_project_name_key unique (project_id, name);
-- replace exclude: drop old gist on organization_id if exists and recreate on project_id
alter table public.fiscal_period drop constraint if exists fiscal_period_organization_id_excl;
alter table public.fiscal_period drop constraint if exists fiscal_period_no_overlap;
do $$ begin
  alter table public.fiscal_period add constraint fiscal_period_project_no_overlap
  exclude using gist (project_id with =, daterange(start_date, end_date, '[]') with &&);
exception when duplicate_object then null; end $$;

-- indexes
create index account_project_idx on public.account (project_id);
create index fiscal_period_project_idx on public.fiscal_period (project_id);
create index journal_entry_project_idx on public.journal_entry (project_id);
create index journal_entry_project_date_idx on public.journal_entry (project_id, entry_date);
```
